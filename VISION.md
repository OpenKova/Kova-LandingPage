# VISION.md

`kova-agent.ai` is the canonical public front door for Kova Agent. It should help a new user understand the project, start safely, and find the canonical docs, downloads, community, and ecosystem without overstating what the product supports.

## Boundaries

- Documentation belongs on `docs.kova-agent.ai`; this site should summarize and route to the canonical page.
- Product downloads are linked from GitHub releases and documented here.
- The site is a static pre-rendered site; dynamic content (status, blog, docs) lives on dedicated subdomains.
- Community content (testimonials, press, showcase) lives in static data files embedded at build time.
